## 📖 关于本项目

这个项目整理了一套面向 **AI / 大语言模型（LLM）** 学习者的学习路线。

整体按照以下五个方向组织：

```text
┌──────────┐
│   科普   │  → 建立 AI / LLM 整体认知
└────┬─────┘
     ↓
┌──────────┐
│   入门   │  → 学习机器学习、深度学习与 LLM 基础
└────┬─────┘
     ↓
┌──────────┐
│   论文   │  → 学习论文检索、阅读与研究方法
└────┬─────┘
     ↓
┌──────────┐
│   实战   │  → 通过开源项目理解 LLM 内部原理与工程实践
└────┬─────┘
     ↓
┌──────────────┐
│ 工具/Skills  │ → 提升 AI Coding 与科研/开发效率
└──────────────┘
```

> **建议学习方式：**
>
> 不必严格按照单一路线学习，可以根据自己的基础和目标选择对应模块。
> 如果是 AI / LLM 初学者，可以按照 **科普 → 入门 → 实战 → 论文 → 工具** 的顺序逐步学习。

# 💻 04 · 实战

实战部分重点通过开源项目和代码实践理解 LLM、Agent 和生成式 AI 的内部原理。

---

## 🤖 AI Agent

### AI Agent Book

围绕：

> **Agent = LLM + Context + Tools**

这一核心公式，通过多个章节学习 AI Agent 的原理与工程实践。

🔗 [GitHub](https://github.com/bojieli/ai-agent-book)

---

## 🧠 LLM 编程实践

### Dive into LLMs

《动手学大模型》系列编程实践教程。

由上海交通大学相关课程讲义拓展而来，提供大模型相关的入门编程参考。

🔗 [GitHub](https://github.com/Lordog/dive-into-llms)

---

### LLMs-from-scratch

《Build a Large Language Model From Scratch》的官方代码库。

通过从零开始实现大型语言模型，逐步理解 LLM 的内部工作原理。

🔗 [GitHub](https://github.com/rasbt/LLMs-from-scratch)

---

## 🏗️ 从零训练语言模型

### ZGCM-1

一个 7.39B 参数规模的密集语言模型，从零开始训练。

🔗 [GitHub](https://github.com/zgcagi/ZGCM-1)

---

### MiniMind

从 0 开始训练超小型语言模型。

项目还扩展了：

* MiniMind-V
* MiniMind-O
* MiniMind-dLM
* MiniMind-Linear

可以用于进一步了解视觉、多模态以及不同类型语言模型的实现。

🔗 [GitHub](https://github.com/jingyaogong/minimind)

---

## ⚡ 极简 GPT

### MicroGPT

一个约 200 行纯 Python 实现的 GPT 项目。

通过极简代码理解 GPT 的训练与推理过程。

🔗 [项目介绍](https://karpathy.github.io/2026/02/12/microgpt/)

# ⭐ 学习建议

### 01. 不要只看课程

建议采用：

> **学习理论 → 阅读代码 → 动手实现 → 阅读论文 → 复现项目**

的方式进行学习。

---

### 02. 不要一开始就追求复杂模型

可以从：

```text
MicroGPT
    ↓
LLMs-from-scratch
    ↓
MiniMind
    ↓
更复杂的 LLM / Agent 项目
```

逐渐深入。

---

### 03. 理论与实践结合

推荐采用：

```text
课程
 ↓
基础知识
 ↓
开源项目
 ↓
代码实践
 ↓
论文阅读
 ↓
项目复现
 ↓
自己的研究 / 项目
```
